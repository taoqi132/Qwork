# Qwork 迁移基线与实施记录

## 产品约束

以最终交付为中心，保留单聊、群聊和四种模式。支持六种本机 CLI。附件不解析正文，由 Agent 读取路径；不增加应用服务器或必需云账号。不把多 Agent 认可当作事实正确性的保证。

## 原项目审计

原项目为 Vue + Electron + Node.js；实际编排包括本地 workspace、自然讨论、版本确认、双 Agent 审查、主持检查和讨论后执行。旧名称和主题均进入提示词；智能组队存在实际路由。旧前端依赖 Electron preload，不能直接变为普通网页。

复用范围精确限定于 CLI 运行、协议解析、发现、原生配置、凭据隔离、权限响应和进程取消的静态依赖闭包。初始迁入 34 个上游文件（含测试及支持模块），随后补入 agent-output 测试夹具；未复制整个旧后端。legacy 文件的原始哈希记录在 upstream-manifest.json。discovery 增加可选 allowlist 与 Windows Node 脚本入口处理；OpenClaw gateway/health 同样经过 Windows 入口正规化；CLI 取消在 taskkill 失败或迟延时增加自有子进程句柄终止，修改均有标记。

## 迁移矩阵

| 功能 | 实现与变化 |
| --- | --- |
| 六种 Agent | TS AgentService 使用原生配置，运行时只检测 allowlist |
| 单聊 | 使用选定 Agent 与当前任务、近期历史、附件清单；默认不授予写权限 |
| 群聊 | TS Workflow 统一四种模式及结果检查，单群单活跃运行 |
| 角色设置 | 圆桌/接力：主持者与成果负责人；独立分析：成果负责人；制作检查：制作者，其余成员全部检查 |
| 自动结束 | 圆桌/接力由主持者判断可推进，不要求全员投票；独立分析单轮；文件检查绑定版本 |
| 智能组队 | 改为可查看的小团队推荐；按本机可用情况筛选，不声称模型专长 |
| 名称/目标 | 名称只显示；目标进入后续任务背景，运行时冻结 |
| 目录 | 全局默认根目录，每群独立覆盖；有附件时禁止直接改目录 |
| 附件 | 原文件不改动，应用只处理副本/元数据/哈希和路径 |
| 历史 | 每群记录包含多次任务，支持改名、删除，保留磁盘文件 |
| UI | 全新首页四模式、任务概述、折叠发言、成果区、设置页 |
| 恢复 | 未结束任务重启后标为已中断，不自动重放写操作 |
| 制作重试 | 保留讨论结论，复制阶段文件到新运行目录，仅重新制作与检查 |
| 文件检查 | 存在/哈希由应用检查，内容与版式由 Agent 报告；当前不内置 Office 解析渲染 |

## 模块职责

- src/shared/types.ts：稳定的跨进程数据协议。
- src/main/validation.ts：IPC 输入运行时校验。
- src/main/storage.ts：原子 JSON 持久化、路径检查、附件副本和产物哈希。
- src/main/agents.ts：六 CLI 发现、原生配置、权限与流式事件边界。
- src/main/workflow.ts：冻结输入、四模式运行、用户决定、执行与检查、取消。
- src/main/receipts.ts：结构化回执校验，缺失或无效不视为通过。
- src/main/index.ts / preload.ts：可信界面 IPC、文件选择、输出操作与应用生命周期。
- src/renderer：Vue/TS 首页、设置、群聊和成果窗口。

## 必须通过的验收

1. 轮数上限为六时，可在第一/二轮完成收敛并进入制作。
2. 并发参与者收到相同冻结提示词，不能读取同批回复。
3. 顺序参与者看到前序已提交发言。
4. 缺失回执、错版认可、成员失败不能标为完整通过。
5. 只有执行者拥有写权限，审查者不同且只读。
6. 没有实际非空文件不宣称文件交付；审查期间文件变化使认可失效。
7. 附件只传路径，改动哈希后拒绝使用旧引用。
8. 取消等待用户决定的任务能正常结束；同群不能重复运行。
9. 重启不会自动重放未知结果的写操作。
10. 在真实 Electron 窗口中完成创建、运行、折叠展开、成果展示、改名和删除。

## 当前有意保留的限制

界面支持中文/英文，默认跟随系统语言并可手动覆盖。JSON 适合首版本地单进程使用，未引入 SQLite。尚未迁入原生会话复用、自动断点恢复、云连接器、知识库、第三方 Skills 管理、Agent 自动安装。输出检查不内置 Office 格式解析或视觉评估。六 CLI 的协议回归测试与真实提供者测试应分开报告。

这是一版围绕核心需求重建的 Qwork，不声称已经逐项复刻旧应用全部隐藏行为。
