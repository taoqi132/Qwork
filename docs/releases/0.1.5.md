# Qwork 0.1.5

## 更新

- 启动时先检查本机 Agent，展示逐项状态与检测进度，完成后进入工作台；支持跳过等待。
- 提供 CLI 快捷安装入口。Codex、Claude Code、WorkBuddy、OpenClaw 和 Qwen Code 采用 Meldwork 的固定 npm 配方与校验逻辑，确认后安装，支持取消和安装后检测；Zcode 提供官方说明入口。
- 支持同类 Agent 的两个独立实例，分别保存成员模型、角色、进度和回复。保留每类两个实例、OpenClaw 一个实例的限制，移除群聊合计六人的上限。
- 修复已有群聊设置的响应式对象克隆错误；取消编辑不会修改原配置。
- 修复同类双实例被提示成员不足，以及 WorkBuddy 未指定模型时下拉框显示空白。
- Agent 已完成回答并报告部分工具、文件或网络受限时，保留成员与回答并记录警告，避免据此直接移出群聊；未完成的核验不能视为审查通过。
- 完善附件拖入与粘贴、按成员区分的执行记录、运行状态及历史数据迁移。

## 验证范围

代码检查和模拟 Agent 测试用于验证编排、状态与权限边界；Electron 验收使用隔离数据。它们不代表真实提供者的全部文件读取、联网或模型能力已经通过验收。CLI 安装入口验收不实际下载或安装软件。

Windows 安装包仍未配置数字签名。升级保留原有用户数据；Agent 原生登录与模型配置继续由各 CLI 管理。
