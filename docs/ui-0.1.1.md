# Qwork 0.1.1 界面与交互更新

1. 最新一条 Agent 完整回答默认展开，较早回答默认收起；仍可手动展开其他回复。
2. Enter 发送；Ctrl+Enter、Shift+Enter 和 Meta+Enter 换行。中文输入法确认候选时不会误发送。
3. 新建群聊先展示四模式的说明、适用场景和流程；选择后进入名称、目标、成员和目录设置。单聊与编辑已有群聊不强制经过模式选择。
4. 移除无用的“新任务”占位名称；单聊使用独立提示，多 Agent PPT 快捷入口进入创建群聊向导。
5. 默认按照电脑语言选择中文或英文；设置可改为跟随系统、中文或英文，保存后即时更新。原始消息、用户命名和 Agent 输出不被翻译覆盖。
6. 首页移除英文装饰和大面积宣传首屏，四模式前置为清晰的两列卡片；说明和场景标签增大字号与对比度。
7. 高级协作设置默认展开。
8. 群聊展示本次参与的全部 Agent 和阶段流程。活跃成员、并发成员和返回内容状态均来自运行数据；不会将未知内部状态描述成“正在思考”。

验证：35 项 Qwork 测试、类型检查、生产构建通过；原生凭据/权限回归 34 项通过、10 项按平台条件跳过。真实 Electron 窗口已验证向导、键盘操作、展开行为、中英文切换、原文保留、单聊跳转和活跃成员状态。
