# Briefs to try / 示例任务

[English](../README.md) · [简体中文](../README.zh-CN.md)

These are prompts, not completed example outputs. File support depends on your CLI, model and local tools. Use your own materials, grant writes only to the intended directory, and inspect the results.

以下为任务描述，不是已经实测完成的产物。文件能力取决于 CLI、模型和本机工具。请使用自己的资料、限定写入目录，并验收结果。

## 1. Roundtable Discussion → management presentation

Read the attached project materials. Create a 12-slide management presentation covering progress, key metrics, risks and next steps. Identify missing or conflicting figures. Deliver a PPTX file and a short source/check report. Only claim layout checks if pages were actually rendered.

**圆桌讨论 → 项目汇报 PPT**：读取附件资料，制作 12 页管理层汇报，包含进展、关键指标、风险和下一步计划。指出缺失或矛盾数据，交付 PPTX 与简短来源/检查说明。实际渲染过页面后才能声称检查了排版。

## 2. Create & Review → improve an existing draft

Improve the attached report while preserving facts and source attribution. One creator revises; all other selected agents independently check consistency and unsupported claims. Deliver a revised document and unresolved questions. Stop revising once the current version meets the criteria.

**制作检查 → 完善报告**：保留事实和来源，修改附件报告。一位制作者修订，其余已选 Agent 独立检查口径与无依据结论。交付修订文件和待确认事项，当前版本满足要求即结束。

## 3. Relay Discussion → requirements to implementation plan

Start from the brief: clarify requirements, examine implementation risks, then develop an executable plan. Each contributor should build on previous committed replies. Deliver a plan with acceptance criteria and unresolved dependencies.

**接力讨论 → 需求到实施方案**：依次澄清需求、检查实现风险、完善执行计划。后续发言基于前序已提交意见，交付带有验收标准和待解决依赖的方案。

## 4. Independent Analysis → compare alternatives

Independently propose three approaches to the task. Compare assumptions, trade-offs and unknowns, then produce a decision memo. Keep disagreements visible; do not label independent opinions as consensus.

**独立分析 → 方案比较**：独立提出不同方案，比较假设、取舍和未知因素，整合为决策备忘录。保留分歧，不把独立意见标为共识。

Independent Analysis uses one analysis-and-synthesis pass. File creation is optional. Roundtable and Relay rely on a moderator’s readiness decision; review of actual files remains separate.

独立分析只做单轮分析与汇总，可选择后续制作文件；圆桌和接力讨论由主持者判断可推进，实际文件仍需独立检查。
